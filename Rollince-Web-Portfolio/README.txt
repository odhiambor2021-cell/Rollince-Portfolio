HOW TO USE
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser (or use Live Server).
4. Replace:
   - +254 700 000 000 with your real WhatsApp number.
   - yourname@example.com with your real email.
   - Demo project content with your real project screenshots/links.
5. When ready, upload the three files to your hosting service.

IMPORTANT
The contact form currently opens the visitor's email application. For a real online form that stores/sends submissions without opening email, connect it to a backend or a form service.
